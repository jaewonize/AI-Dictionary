# 리뷰 확인 항목 (해커톤 PoC 경량 기준)

리뷰 원칙과 심각도(`[필수]`·`[권장]`·`[참고]`)는 AGENTS.md "코드 리뷰 규칙"을 따른다.

- **중요 원칙:** 해커톤 PoC 속도를 위해 **엔터프라이즈·프로덕션 수준의 보완**(프로세스 그룹 시그널 관리, 서버 드레이닝, CSRF·세밀한 보안 헤더, 모든 경계값·스키마 방어, 단위 테스트 커버리지·문서 강제 등)을 요구하거나 `[필수]`로 분류하지 않는다.
- 아래 항목 중 **이번 변경과 직접 관련되고 실제 데모 실행을 깨뜨리거나 시크릿을 유출할 수 있는 문제**만 점검한다.

## 최소 핵심 점검 목록

- **실행 오류·크래시 (`[필수]` 후보):**
  - 주요 실행·데모 경로에서 `null`/`undefined` 참조나 처리되지 않은 예외로 앱·화면이 멈추지 않는가.
  - 실제 실패(API 오류·파일 읽기 실패 등)를 정상 빈 결과로 조용히 삼켜 데모 오동작을 숨기지 않는가.
- **비동기·화면 상태:**
  - 모델 호출·검색 등 시간이 걸리는 요청 중 중복 클릭이나 늦게 도착한 이전 응답이 최신 화면 결과를 덮어써 데모가 꼬이지 않는가(실제 재현 가능성이 높을 때만 지적).
- **계약 일치 (`[필수]` 후보):**
  - 화면과 서버(또는 데이터 파일)가 함께 쓰는 API 경로·필드명·응답 형식을 바꿨을 때 호출하는 쪽도 함께 맞춰졌는가.
- **외부 API·모델 호출:**
  - LLM·외부 API 호출이 실패하거나 지연될 때 프로세스 전체가 죽지 않고 오류 상태를 반환·표시하는가.
- **보안 최소선 (`[필수]`):**
  - diff에 토큰·API 키(`sk-`·`ghp_`·`github_pat_`·`AKIA`·`AIza` 등), `.env*`(`.envrc` 포함) 파일, 민감한 개인 정보가 포함되지 않았는가. (예제 파일이 필요하면 `.env*` 대신 `env.example` 이름을 쓴다.)
- **작업 범위:**
  - 요청받지 않은 `workspace/` 밖 파일(발표 자료·합성 데이터 등)을 임의로 수정·삭제하지 않았는가.
