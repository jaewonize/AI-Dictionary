# AI ( ) Dictionary 데모 영상

실제 `/demo` 화면을 별도 Chrome에서 캡처한 영상입니다. 1920×1080, 30fps, H.264 MP4이며 소리는 없습니다. 한국어 자막이 영상에 포함되어 있습니다.

| [시나리오 2](B.mp4) | 40초 | 욕실 최저 견적과 계약 금액 비교 | [SRT](B.srt) |
| [시나리오 3](W.mp4) | 40초 | 작년 송년회와 4년 전 생일의 와인 사진 찾기 | [SRT](W.srt) |

## 보는 방법

위 영상 링크에서 파일을 열거나 다운로드합니다. 이 폴더 전체를 내려받은 뒤 `index.html`을 브라우저에서 열면 합본과 개별 영상을 한 화면에서 볼 수 있습니다. GitHub에서 `index.html`을 클릭하면 재생 페이지 대신 소스가 표시됩니다.

## 영상에 포함된 내용

- 시나리오 1·3은 저장된 실제 실행 기록을 재생한 것입니다. 녹화 중 AI API를 새로 호출하지 않았습니다.
- **시나리오 2는 설계 미리보기**입니다. 해당 표시를 영상 내내 유지했습니다.
- 반복되는 사전 준비 구간은 생략했고, 각 시나리오의 시작 화면을 4초, 결과를 6~8초 유지했습니다.
- 폰 자료는 예시 자료이며, 실제 관람객 사진은 기존 데모의 흐림 처리 사본을 사용했습니다.
- 화면 자막과 별도 SRT는 같은 내용입니다. 이미 자막이 들어 있으므로 일반 재생 시 SRT를 추가로 켤 필요는 없습니다.

`manifest.json`은 원본 HTML의 해시와 편집 구간 설명, `verification.json`은 해상도·프레임 수·전체 디코딩 및 화면 확인 결과입니다.
