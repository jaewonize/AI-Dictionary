로고 사용 규정 안내문

대상: 보름달베이커리 협력 제작처 / 배포일: 2025-06-10 / 작성: 스튜디오 여백

본 안내문은 브랜드 로고를 외부 제작처에서 사용할 때 지켜야 할 최소 규정을 정리한 문서입니다. 전체 내용은 디자인 시스템 가이드 문서를 참고하십시오.

허용 사용

매체사용 형태최소 크기
인쇄 패키지가로형 1색 또는 2색가로 24mm
현수막과 배너가로형 풀컬러가로 200mm
유니폼 자수아이콘 단독가로 30mm
SNS 프로필세로형 또는 아이콘가로 80px
영수증과 스티커아이콘 단독 1색가로 12mm

금지 사항

  • 비율 변경, 기울임, 그림자 및 외곽선 추가
  • 승인되지 않은 컬러로 로고 채색
  • 로고를 다른 도형이나 텍스트와 결합해 새 마크처럼 사용
  • 저해상도 이미지 확대 사용, 300dpi 미만 인쇄 금지

파일 요청 절차

원본 파일은 보름달베이커리 운영팀을 통해 요청하며 제작처 직접 요청은 받지 않습니다. 파일 형식은 인쇄용 AI와 PDF, 화면용 PNG와 SVG를 제공합니다.
